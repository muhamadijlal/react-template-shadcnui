# React Template (Vite + Tailwind + shadcn/ui)

Template ini menggunakan stack modern untuk membangun aplikasi React yang cepat dan scalable.

## 🚀 Tech Stack

- ⚡ Vite
- ⚛️ React 19
- 🎨 Tailwind CSS v4
- 🧩 shadcn/ui
- 🧭 React Router v7
- 🎯 CVA + Tailwind Merge
- 🎬 tw-animate-css
- 🎨 React Icons & Lucide

## 📦 Requirement

- Node.js `v22.x`
- npm `v10.x`
